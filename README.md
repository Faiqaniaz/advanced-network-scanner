# Advanced Network Scanner

## Description
Advanced Network Scanner is a Python-based GUI application that performs multithreaded port scanning on a target IP address. It identifies open ports, detects basic services, and provides real-time scanning progress with export functionality.

The project is designed for educational and ethical cybersecurity learning purposes.

---

## Features

- Multithreaded port scanning for faster performance
- Detection of open ports on target systems
- Basic service identification (HTTP, SSH, FTP, etc.)
- Simple banner grabbing from open ports
- Real-time progress tracking
- Graphical user interface using Tkinter
- Export scan results in TXT, CSV, and JSON formats
- Input validation for IP addresses and port ranges

---

## Tech Stack

- Python 3
- Socket Programming
- Threading (Concurrent Futures)
- Tkinter
- CSV and JSON modules

## Usage

Enter the target IP address
Enter start and end port range
Click Start Scan
View results in the interface
Export results if needed

## Disclaimer

This tool is developed strictly for educational and ethical cybersecurity purposes. Unauthorized scanning of networks or systems without permission is not allowed.
